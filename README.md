# 🧱 Flutter GridView.builder Example

This repository demonstrates how to use the powerful `GridView.builder` widget in Flutter to create dynamic, scrollable, and responsive grid layouts. Whether you're displaying a photo gallery, product catalog, or list of cards — `GridView.builder` is your go-to widget!

---

## 📦 What is GridView.builder?

`GridView.builder` is a constructor in Flutter's `GridView` class that lets you build a scrollable 2D array of widgets dynamically. It only builds the visible widgets on screen, making it memory-efficient and performant for long lists.

---

## 🚀 Why Use GridView.builder?

- 🔄 **Efficient lazy loading** – builds items on-demand
- 🎯 **Highly customizable** – define how many items per row, spacing, etc.
- 📱 **Responsive layouts** – adapts well to different screen sizes
- 💡 **Great for dynamic content** – like product grids, image galleries, etc.
